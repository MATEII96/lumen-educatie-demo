# LUMEN — demo educațional

**DEMO pentru Olimpiada Națională de Dirigenție.** Experiență web interactivă, în limba română, pentru explorarea lecțiilor prin jocuri.

## Ce conține

- 16 preseturi demonstrative, câte două pentru fiecare dintre cele opt discipline prezentate în bibliotecă.
- Escape room 3D „Arhiva celor trei sigilii”, cu trei camere, indicii și mecanisme de investigație.
- „Rețeaua vie”, joc de explorare a relațiilor trofice, cu un simulator ecologic didactic simplificat.
- „Balanța necunoscutei”, atelier matematic cu ecuații în mai multe etape.
- Selector pentru școală și clasele V–VIII, teme întunecată/luminoasă, bibliotecă de jocuri și spațiu demonstrativ pentru profesori.

## Utilizare

Site-ul este static și nu necesită compilare sau instalarea de pachete. Se poate deschide prin `index.html` sau publica pe GitHub Pages din rădăcina ramurii `main`.

În spațiul profesorului, transformarea lecției este o demonstrație locală bazată pe extragerea simplificată a termenilor din text. Nu este conectat un API AI, un cont școlar sau un serviciu de stocare; materialul introdus rămâne în browser.

## Încadrare didactică

Referința generală este programa pentru gimnaziu aprobată prin OMEN nr. 3393/2017: [pagina oficială a Ministerului Educației](https://www.edu.ro/Ordin_ministru_3393_2017). Jocurile sunt preseturi demonstrative; profesorul verifică potrivirea cu programa clasei și cu ediția manualului folosită.

Școala și clasa afișate implicit sunt fictive: „Școala Demo · Clasa a VII-a B”.
